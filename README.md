# shawty-playground

A little surprise page for Praebooboo 🩷

Open `index.html` in a browser (made for iPhone first, also works on iPad and Mac).

1. She picks how she's feeling today.
2. A gift box appears. Tapping it opens the lid, the box disappears, and a kissing kitten rises up with hearts and dancing kittens in the corners.

`kiss.jpg` and `dance.jpg` are the kitten pictures. To use animated versions, add `kiss.gif` / `dance.gif` and change the `src` in `index.html`.
